# Slate Gambit(検証プロトタイプ)

パーティで地下 5 階までのダンジョンを探索し、最深部の秘宝を持ち帰るゲームの検証版。戦闘は RoboSport 型の
「全員が行動を予約 → 敵味方を同時に解決」するタクティカルなターン制。

起動するとメインメニューが出る。初めての人は「チュートリアル」(操作ガイド 5 ページと、移動・攻撃・防御・魔法・担ぐ・足払いを 1 つずつ覚える 5 つのレッスン。画面の上に次にやることが出る)から。「キャンペーン」は従来の地下 5 階の探索(保存あり)、「ミニゲーム」は 10 分ほどで終わる 3 ステージの連戦(保存なし)。キャンペーンは宿・馬小屋で保存した時点から、またははじめから難易度(Easy / Normal / Hard)を選ぶ。地上の城の入口から始まり、ダンジョンは毎回ランダムに作られる。目的は「地下 5 階の秘宝を見つけ、地上へ持ち帰る」こと。
地上は城の中で、中央の大広間の左右に宿(有料で全快)・馬小屋(無料で HP 半分まで)・道具屋(食料・回復薬)・療養所(有料で気絶者を復帰)・銀行(預金は野盗に盗まれない)・教会(有料で 1 度だけ気絶を防ぐ加護)が並ぶ。休憩には食料が要り、泉は使うと酸の泉に変わることがあるので、潜って宝箱と敵からゴールドを稼ぎ、地上で回復・補給してまた潜る。地上には噂(本当のことも嘘もある)を話す住人がいるが、そのうち 2 割は住人に化けた盗人で、見かけでは分からない。地下 1〜2 階にはゴールドを盗んで逃げる野盗が出る。地上にもごくまれに魔物が入り込む。
階段を行き先に選んだ誰か 1 人が着くと全員で別の階へ移り(上り下りとも可。離れた階の状態は残る)、宝箱と敵でゴールドを集め、敵を倒して経験値をためるとレベルが上がる。

## 動かし方

```sh
npm install
npm run dev          # http://localhost:5173/ (同じネットワークのスマホからは npm run dev -- --host)
npm test             # ルールエンジンの単体テスト
npm run build        # dist/ に静的ファイルを出力
```

チュートリアルのレッスンは `?tutorial=1`(レッスン 1)または `?tutorial=ID` で直接始められる。ID は `tutorial`・`tut-guard`・`tut-fire`・`tut-carry`・`tut-trip`。ミニゲームは `?minigame=caster`(`&stage=1` で 2 ステージ目から)で直接始められる。ID は `caster`(詠唱封じ)・`rescue`(救出作戦)・`alarm`(夜警)・`trials`(三つの試練)。

URL に `?seed=123&diff=normal` を付けると、マップ(シード)と難易度を指定して直接始められる(地上の町から始まる)。`&floor=5` を足すと地下 5 階から始まる(デバッグ用)。
バランス確認は `npm run playtest`(`GAMES=100` で回数、`VARIANTS=all` で途中の階から始める場合も、`TRACE=シード DIFF=hard` で 1 戦の経過)。

## 操作

- 下のカードで味方を選び、行動ボタンを押してから盤面のマスや敵をタップして予約する(予約済みのほかの味方は、今操作しているティックの予定位置へ盤面上で動いて見える)
- 移動モードでは、床をタップすると経路を予約、敵をタップすると攻撃を予約(戦士で隣の小型の敵をタップすると、押し返して前進する移動を予約)
- 全員の予約が済んだら「実行」(リターンキーでも可)。予約していない残り AP は、敵が見えていれば防御、見えなければ待機になる。敵味方の行動が 8 ティックで同時に再生される
- 再生中は 一時停止 / コマ送り / 速度変更 / スキップ、終了後は上部の「もう一度見る」
- ドラッグで盤面を移動、ホイールまたはピンチで拡大縮小
- ボタンにマウスを乗せると、パネルに 1 行の説明が出る
- ⚙(メニュー → キャンペーン → 設定)から敵の予兆表示(頭上の印と、狙っている味方へのオレンジの点滅ライン)・画面外の目印・全員移動の隊列を設定できる

## ルール要約

詳しい仕様は [ゲーム仕様.md](ゲーム仕様.md) を参照。

- 1 ターン 8 ティック、各キャラ AP 8。移動 1 / 攻撃 3 / 魔法 3 / 防御 1(被ダメージ半減)/ 休憩 1(戦闘中も半分回復するが被ダメージは減らない)
- 休憩: 自分で予約した休憩のティック数に応じて回復する(8 ティックで HP が最大値の 20%、MP 2)。回復したターンは食料を 1 つ使い、食料が無いと回復しない。予約で余った AP と全員移動はただの待機で、回復も食料の消費もしない。戦闘中(敵が見えている)は回復量が半分。「全員休憩」ボタンは全快・攻撃を受ける・敵が隣に来る・食料切れまで休ませ続ける(敵が近づく様子は再生して見せる)
- 攻撃・魔法は最後のティックで発動する。近接・弓・回復・蘇生はユニット狙い(離れられると不発)、火球はマス狙い。火球は見えないマスにも撃てるが、着弾点が最大 1 マスずれる
- 同士討ちあり: 矢は射線上で最初に当たったユニットに、火球は範囲内の全員に当たる。ただし撃つ瞬間に味方が射線上にいれば矢は撃たない(AP は消費)
- 味方のマスは通り抜けられるが、敵のマスは通れず敵とのすれ違いも不可。ただし重装の戦士(および大型の敵)は、向かってこない小型の敵の後ろが空いていれば 1 マス押し返して前進できる(直後の 1 ティックは踏ん張り)。同じマスに 2 体は止まれない(重なったら元からいた側が優先、移動者同士は乱数)
- 移動は上下左右のみ。近接攻撃・迎撃・蘇生・担ぐの「隣」は斜めを含む 8 マス(壁の角の隙間越しは除く)
- 攻撃で届かない敵を選ぶと接近攻撃(近づいてから攻撃。残り AP 全部)になる。ただし攻撃モードで遠隔職が射線上に味方のいる敵を選んだときは、接近攻撃に切り替えずその場での射撃を予約する(発動ティック時点で前の味方がどく予約を入れていればそのまま射線が通る)
- 敵の予兆表示がオンなら、敵の頭上に意図(「!」攻撃 / 「強5」強攻撃 / 「迎」待ち伏せ / 「炎」「詠」範囲魔法 / 「笛n」警報)と、単体の味方を狙う敵からのオレンジの点滅ラインが出る
- 階段を行き先に選んで(階段のマスをタップ)着くと、そのターンの終わりにパーティ全員がその階へ移る。通り抜けた・たまたま止まっただけでは移らない。宝箱は通り抜けでも開く
- 敵を倒すと全員(気絶中も含む)に経験値が入り、レベルが上がると最大 HP・攻撃力などが増える
- 職業ごとの特技: 戦士は「かばう」「強攻撃」、盗賊は「足払い」「強攻撃」、魔法使いは「火球」、僧侶は「回復」「蘇生」「聖光」。近接攻撃は敵を挟むと強くなり、狙った敵が先に倒れたら別の敵に狙いが移る
- 休憩して回復すると、物音で遠くから敵が近づいてくることがある(戦うか、休む場所を選ぶ)
- 防御中は被ダメージ半減。HP 0 で気絶し、僧侶の蘇生・回復の泉・地上の療養所で復帰。泉は使うたびに 33% で酸の泉(触れると最大 HP の 20% のダメージ)に変わり、酸の泉も触れるたびに 33% で戻る。地上から潜り直しても戻る
- 扉は閉じていて視界を遮り、上下左右に隣接すると開く。誰も近くにいなくなって 5 ターンで自動で閉まる。見えている敵だけを描き、倒れた敵は 3 ターンで消える
- 地上の城: 大広間の下端が入口、上端が地下への階段。左右の部屋に宿(レベルの合計 × 5 G で全快)・馬小屋(無料で HP 50% まで)・道具屋(食料 8 G・回復薬 40 G)・療養所(レベル × 30 G で気絶者を復帰)・銀行(預金は盗まれない)・教会(レベルの合計 × 10 G で、地上へ戻るまで 1 度だけ気絶を防ぐ)。施設の部屋(中は 5×5 マス)に入ると、どのマスでも持ち物の列の右端にボタンが出る。施設を使っても時間は進まない
- 敵を倒すとゴールドが入る。野盗(地下 1〜2 階)は攻撃が当たるとゴールドを盗んで逃げ、見られずに 2 ターンで逃げ切る。倒せば取り返せる
- 地上の住人は敵ではなく、隣に行くと(通り過ぎるだけでも)噂を話す(6 割が本当)。2 割は住人に化けた盗人で、近づいて殴った時点で正体を現して盗む。盗人は人間なので弱い
- 地上では受けるダメージが半分になり、魔法(火球・回復・蘇生・聖光)は使えない
- 銀行の預金には、ゲームを起動するたびに 5% の利息が付く(1% の確率で暴落して 30% を失う)
- 気絶した味方は担いで運べる(担ぐ・降ろす 1AP、運搬中の移動は 1 マス 2AP)
- 迎撃ボタン(条件付き行動): 遠隔は警戒射撃(動いて射程に入った敵を撃つ。味方越しには撃たない)、近接は迎撃(隣の敵をランダムに攻撃。動いて来た敵には即座に反応)
- 移動中に新しい敵を見たら、残りの移動を防御に切り替えて止まる(常に有効)
- ターンごとにブラウザへ自動保存し、開き直すと続きから。全員移動の隊列の順は設定で指定できる

## バランス検証

```sh
npm run playtest                 # 調整案ごとに自動対戦して比較(GAMES=回数、MAX_TURNS=上限)
TRACE=1000 npm run playtest      # シード 1000 の 1 戦をターンごとに追跡(地上から。START=5 で地下 5 階から)
VARIANTS=budget BUDGET="hard=26/38/52/66/59 normal.3=24,28" npm run playtest   # 敵の点数(全階 / 1 つの階)を差し替えて比較
```

比較する調整案は `tools/playtest.sim.ts` の `VARIANTS`、パーティの自動操作は `tools/partyBot.ts`。

テキストで 1 ターンずつ手で遊ぶハーネスもある(使い方は `tools/manual.sim.ts` の先頭)。

## 構成

- `src/core/` — ルールエンジン。DOM に依存せず、`resolveTurn(state, plans)` が唯一の進行手段。乱数はシード付きで決定的
- `src/data/` — 職業・モンスター・魔法の数値、表示文言
- `src/ui/` — Canvas 描画、入力、再生、操作パネル

ルール部分を描画から切り離してあるため、将来はサーバーや他の端末で同じコードを動かして遠隔マルチプレイに発展できる。
