# Slate Gambit(検証プロトタイプ)

パーティで地下 5 階までのダンジョンを探索し、最深部の秘宝を持ち帰るゲームの検証版。戦闘は RoboSport 型の
「全員が行動を予約 → 敵味方を同時に解決」するタクティカルなターン制。

開始時に難易度(Easy / Normal / Hard)を選ぶ。ダンジョンは毎回ランダムに作られ、目的は「地下 5 階の秘宝を見つけ、地下 1 階の入口の階段まで持ち帰る」こと。
階段を行き先に選んだ誰か 1 人が着くと全員で別の階へ移り(上り下りとも可。離れた階の状態は残る)、宝箱でゴールドを集め、敵を倒して経験値をためるとレベルが上がる。

## 動かし方

```sh
npm install
npm run dev          # http://localhost:5173/ (同じネットワークのスマホからは npm run dev -- --host)
npm test             # ルールエンジンの単体テスト
npm run build        # dist/ に静的ファイルを出力
```

URL に `?seed=123&diff=normal` を付けると、マップ(シード)と難易度を指定して直接始められる。`&floor=5` を足すと地下 5 階から始まる(デバッグ用)。
バランス確認は `npm run playtest`(`GAMES=100` で回数、`VARIANTS=all` で途中の階から始める場合も、`TRACE=シード DIFF=hard` で 1 戦の経過)。

## 操作

- 下のカードで味方を選び、行動ボタンを押してから盤面のマスや敵をタップして予約する
- 移動モードでは、床をタップすると経路を予約、敵をタップすると攻撃を予約
- 全員の予約が済んだら「実行」(リターンキーでも可)。予約していない残り AP は、敵が見えていれば防御、見えなければ休憩になる。敵味方の行動が 8 ティックで同時に再生される
- 再生中は 一時停止 / コマ送り / 速度変更 / スキップ、終了後は上部の「もう一度見る」
- ドラッグで盤面を移動、ホイールまたはピンチで拡大縮小
- ボタンにマウスを乗せると、パネルに 1 行の説明が出る
- ⚙ から敵の予兆表示の切り替え、デバッグ表示(敵の計画・視界制限の解除)、シード指定

## ルール要約

詳しい仕様は [ゲーム仕様.md](ゲーム仕様.md) を参照。

- 1 ターン 8 ティック、各キャラ AP 8。移動 1 / 攻撃 3 / 魔法 3 / 防御 1(被ダメージ半減)/ 休憩 1(戦闘中も半分回復するが被ダメージは減らない)
- 休憩: キャラごとに休んだティック数に応じて回復する(8 ティックで HP が最大値の 20%、MP 2)。戦闘中(敵が見えている)は回復量が半分。「全員休憩」ボタンは全員が全快するか敵が見えるまで休ませ続ける
- 攻撃・魔法は最後のティックで発動する。近接・弓・回復・蘇生はユニット狙い(離れられると不発)、火球はマス狙い
- 同士討ちあり: 矢は射線上で最初に当たったユニットに、火球は範囲内の全員に当たる。ただし撃つ瞬間に味方が射線上にいれば矢は撃たない(AP は消費)
- 味方のマスは通り抜けられるが、敵のマスは通れず敵とのすれ違いも不可。同じマスに 2 体は止まれない(重なったら元からいた側が優先、移動者同士は乱数)
- 移動は上下左右のみ。近接攻撃・迎撃・蘇生・担ぐの「隣」は斜めを含む 8 マス(壁の角の隙間越しは除く)
- 攻撃で届かない敵を選ぶと接近攻撃(近づいてから攻撃。残り AP 全部)になる
- 階段を行き先に選んで(階段のマスをタップ)着くと、そのターンの終わりにパーティ全員がその階へ移る。通り抜けた・たまたま止まっただけでは移らない。宝箱は通り抜けでも開く
- 敵を倒すと全員(気絶中も含む)に経験値が入り、レベルが上がると最大 HP・攻撃力などが増える
- 職業ごとの特技: 戦士は「かばう」「強攻撃」、盗賊は「足払い」「強攻撃」、魔法使いは「火球」、僧侶は「回復」「蘇生」「聖光」。近接攻撃は敵を挟むと強くなり、狙った敵が先に倒れたら別の敵に狙いが移る
- 休憩して回復すると、物音で遠くから敵が近づいてくることがある(戦うか、休む場所を選ぶ)
- 防御中は被ダメージ半減。HP 0 で気絶し、僧侶の蘇生か回復の泉で復帰
- 気絶した味方は担いで運べる(担ぐ・降ろす 1AP、運搬中の移動は 1 マス 2AP)
- 迎撃ボタン(条件付き行動): 遠隔は警戒射撃(動いて射程に入った敵を撃つ。味方越しには撃たない)、近接は迎撃(隣の敵をランダムに攻撃。動いて来た敵には即座に反応)
- 移動中に新しい敵を見たら、残りの移動を防御に切り替えて止まる(常に有効)
- ターンごとにブラウザへ自動保存し、開き直すと続きから。全員移動の隊列の順は設定で指定できる

## バランス検証

```sh
npm run playtest                 # 調整案ごとに自動対戦して比較(GAMES=回数、MAX_TURNS=上限)
TRACE=1000 npm run playtest      # シード 1000 の 1 戦をターンごとに追跡(START=5 で地下 5 階から)
VARIANTS=budget BUDGET="hard=26/38/52/66/59 normal.3=24,28" npm run playtest   # 敵の点数(全階 / 1 つの階)を差し替えて比較
```

比較する調整案は `tools/playtest.sim.ts` の `VARIANTS`、パーティの自動操作は `tools/partyBot.ts`。

テキストで 1 ターンずつ手で遊ぶハーネスもある(使い方は `tools/manual.sim.ts` の先頭)。

## 構成

- `src/core/` — ルールエンジン。DOM に依存せず、`resolveTurn(state, plans)` が唯一の進行手段。乱数はシード付きで決定的
- `src/data/` — 職業・モンスター・魔法の数値、表示文言
- `src/ui/` — Canvas 描画、入力、再生、操作パネル

ルール部分を描画から切り離してあるため、将来はサーバーや他の端末で同じコードを動かして遠隔マルチプレイに発展できる。
